# Third-party software

KindleSpouse uses the following upstream projects. Their licenses apply independently of the application source. Generated distribution files include production dependency license texts in `app.asar/dist-electron/licenses`.

The main application source is licensed under MIT. This does not replace the existing AGPL-3.0 licenses in `native/reader`, `native/sleep-cover` and `native/companion/plugin`, or the GPL-3.0-only license of `native/InspectNotebook.mjs` and its converter. Distributors must preserve those licenses and provide the corresponding source required by each component's license. The repository's MIT license does not grant rights to user books, notes, photos, credentials, third-party services or third-party trademarks.

- [Electron](https://github.com/electron/electron), MIT, with Chromium and Node.js notices supplied in the Electron distribution.
- [React](https://github.com/facebook/react), MIT.
- [epub.js](https://github.com/futurepress/epub.js), BSD-2-Clause.
- [KOReader v2026.07.1](https://github.com/koreader/koreader/tree/v2026.07.1), AGPL-3.0. The unmodified official x86_64 AppImage is verified, extracted and invoked as a separate WSL process. Its original licenses, fonts and libraries remain in the runtime directory. The standalone Lua bridge under `native/reader` is provided as source under the accompanying AGPL-3.0 license. Electron communicates with it through local request files and PNG frames. Device reading settings and temporary book copies are never part of the runtime bundle or source repository.
- [PDF.js](https://github.com/mozilla/pdf.js), Apache-2.0.
- [KFX Input](https://github.com/kluyg/calibre-kfx-input), John Howell, GPL-3.0, commit `44db6b6ee8c0094a98c33770575a9070ddb90fda`. The separate Calibre Python worker uses this library only for complete unencrypted PDOC containers. Its full upstream archive, extracted source and license are supplied under `native/tools/kfx-input`. The worker never modifies the original file and does not include DRM removal. [pypdf 5.9.0](https://pypi.org/project/pypdf/5.9.0/), BSD-3-Clause, is supplied there with its complete Python source and original license.
- [Customisable Sleep Screen](https://github.com/pxlflux/customisablesleepscreen.koplugin), AGPL-3.0, commit `feb29ac02bbafeac32ccc9ceb471869c233ea253`. The pinned installer adds the KindleSpouse preset and corrects calls to the statistics writer. The distribution and device package include the complete modified plugin source, original upstream archive and license. The extension under `native/sleep-cover` and the KOReader companion plugin are distributed under their accompanying AGPL-3.0 licenses. Reading statistics and cover rendering remain local to KOReader.
- [JSZip](https://github.com/Stuk/jszip), MIT or GPL-3.0-or-later; this distribution uses the MIT option.
- [fast-xml-parser](https://github.com/NaturalIntelligence/fast-xml-parser), MIT.
- [sanitize-html](https://github.com/apostrophecms/sanitize-html), MIT.
- [Zod](https://github.com/colinhacks/zod), MIT.
- [luaparse](https://github.com/fstirlitz/luaparse), MIT. Lua note files are parsed as data and are never executed.
- [Lucide](https://github.com/lucide-icons/lucide), ISC, with icon attribution in its license.
- [heartleo/zlib v0.0.8](https://github.com/heartleo/zlib), MIT. Its executable and license are downloaded from the pinned upstream release by `npm run tools:install` and bundled in `resources/native/tools` for the Windows build. KindleSpouse is an independent client and is not affiliated with the book service.
- [rclone v1.75.2](https://github.com/rclone/rclone), MIT. Its executable and upstream license are bundled in `resources/native/tools`.
- [Inter](https://github.com/rsms/inter) and [Noto Sans SC](https://github.com/notofonts/noto-cjk), SIL Open Font License 1.1, supplied through Fontsource. Their font assets and licenses are included in the distribution. Apple system fonts are not bundled.
- [Noto Serif SC](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notoserifsc), SIL Open Font License 1.1. The unmodified variable font and original license are obtained from the pinned Google Fonts revision by `tools:fonts`, verified by fixed SHA-256 fingerprints and bundled under `dist/fonts`. Noto Serif SC is used for interface headings and book titles; KOReader document fonts remain independent.
- The optional KOReader device font bundle contains unmodified static [Noto Serif CJK SC and Noto Sans CJK SC](https://github.com/notofonts/noto-cjk/tree/f8d157532fbfaeda587e826d4cd5b21a49186f7c), SIL Open Font License 1.1; [LXGW WenKai](https://github.com/lxgw/LxgwWenKai/tree/7ebd0771fda4285299670f83c398f32f32c7bef8), SIL Open Font License 1.1; and [FandolFang 0.3](https://ctan.org/pkg/fandol), GNU GPL with the upstream font embedding exception. Fixed source URLs, sizes and SHA-256 fingerprints are recorded in `native/reader-fonts.json`. Device packages place the fonts under `koreader/fonts/kindlespouse` and include the original licenses and complete upstream Fandol archive under `kindlespouse/licenses/reader-fonts`. These are selectable reading fonts; they do not replace Amazon system fonts.
- The expanded ten-family device font bundle adds unmodified FandolSong, FandolHei and FandolKai 0.3 under the same Fandol license; [LXGW WenKai GB](https://github.com/lxgw/LxgwWenKaiGB/tree/66b98f37ab83603692fa23d5d4891d0acde938a7) and [LXGW ZhenKai Slab GB 0.827](https://github.com/lxgw/LxgwZhenKai/releases/tag/v0.827), SIL Open Font License 1.1; and [LXGW Neo ZhiSong 1.067](https://github.com/lxgw/LxgwNeoZhiSong/releases/tag/v1.067), IPA Font License 1.0. Their original license files, fixed source URLs and fingerprints are distributed alongside the existing font notices.
- The standalone Kindle companion is compiled with [Go](https://go.dev/), BSD-3-Clause. Its private pairing package includes the Go runtime license, the rclone MIT license, and the Mozilla-derived CA bundle MPL-2.0 license. The CA bundle is obtained from [curl's CA extract](https://curl.se/docs/caextract.html).
- [neo_scribe_to_pdf](https://github.com/sergazin/neo_scribe_to_pdf), GPL-3.0-only, commit `50da8be56403f04505ea08412d3dd0c57494350d`. This independent notebook converter is invoked as a separate command-line program using file input/output. The distribution includes its complete original source archive, modified source, GPL text, dependency licenses and build information under `resources/native/tools/notebook-converter`. The CLI argument parser is explicitly set to Node mode for the Electron Node runtime; dependency versions are pinned. Its local KDF/NMDL decoding is based on John Howell's KFX Input format research and uses Apache-2.0-licensed ion-js. It converts notebook handwriting only, and does not recover Kindle background templates.

[Calibre](https://github.com/kovidgoyal/calibre) is GPL-3.0 software, installed separately by the user. KindleSpouse invokes the user's Calibre executables and documented database API through separate workers. It does not distribute a Calibre executable, Calibre source, ebook content, or DRM removal software.

Build tools and test tools retain their upstream licenses. Their executables are not part of the application's authored source. Full dependency versions and license identifiers are recorded by `package-lock.json` and the generated license index.

The standalone notebook inspection entry `native/InspectNotebook.mjs` is distributed under GPL-3.0-only together with the notebook converter. Its copied entry, bundled executable, complete upstream source and license are included under `resources/native/tools/notebook-converter`. The desktop application communicates with this program through JSON files and process output.

The computer-only Notebook experiment uses [pierspad/notebook.koplugin](https://github.com/pierspad/notebook.koplugin), MIT, commit `fb66d7cfbf57ef67183795530f9bec014abdaffc`. Its complete verified source archive and MIT license remain under the ignored local test tools directory. The engine is not included in the stable device overlay. The experiment's KOReader adapters are AGPL-3.0 under `experiments/notebook/LICENSE`; the separate `decode.mjs` helper uses the existing GPL-3.0-only converter and is covered by `experiments/notebook/DECODE-LICENSE`. Original Amazon NBK files are never rewritten by the experiment.
