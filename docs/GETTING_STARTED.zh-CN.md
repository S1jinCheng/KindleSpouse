# KindleSpouse v0.3.0 使用准备

## 下载什么

在 [Releases](https://github.com/S1jinCheng/KindleSpouse/releases/latest) 下载 `KindleSpouse-0.3.0-Windows-Setup.exe`。这是 Windows x64 安装版，支持 Windows 10／11。普通用户无需下载源码包，也无需安装 Node、Go 或 Python。当前安装包未做代码签名，Windows 可能显示发布者未知。

安装后从桌面启动 KindleSpouse，进入「设置 → 我的 Kindle → 选择设备与使用方式」，按向导选择型号与原生／KOReader 增强模式。书籍、笔记、头像、书源登录和网盘授权由每位用户自行导入、登录或授权，发行包不附带这些个人资料。

## 原生 Kindle 模式

准备好 Kindle 的 Send to Kindle 邮箱、用于发信的邮箱账号及其 SMTP 配置，并将发件邮箱加入亚马逊允许的个人文档邮箱列表。在向导中完成邮箱测试后，可以导入或下载一本书、试读，再确认发送。

此模式不需要越狱或安装 KOReader。是否提供官方网盘 Connections 入口取决于型号和固件，请以设备当前功能为准；原生 Kindle 不会自动领取本项目的 KOReader 网盘目录。原生模式不包含 KOReader 阅读时长、增强笔记回写或定制休眠封面。

## KOReader 增强模式

准备以下条件：

1. 已完成兼容越狱的设备，并安装 KOReader **v2026.07.1**。请先阅读 [KOReader 官方 Kindle 安装说明](https://github.com/koreader/koreader/wiki/Installation-on-Kindle-devices)，向导不会自动越狱或修改固件。
2. 一条能传输数据的 USB 线，首次安装或更新设备组件时使用；安装前保存并退出 KOReader。
3. Google Drive 或 OneDrive 账号。由用户在浏览器完成电脑端与设备端的独立授权，向导核对两端是否使用同一网盘。
4. Kindle 可用的 Wi-Fi。校园、公司网络可能限制设备联网或局域网互通；网盘同步要求设备能访问对应服务。

在桌面向导中完成 USB 组件安装与校验，再拔线、连接 Wi-Fi、启动 KOReader 并保持唤醒。桌面收到本次设备安装的真实回执后，向导才允许完成设置。已配对设备的更新保留原有授权、书籍和阅读设置。配对包包含个人授权，不要分享。

增强组件当前面向 Linux ARMv7，完整实机流程已在 Kindle Scribe 一代验证。不同型号、固件及旧版 KOReader 的兼容性尚未逐一验证；检查不通过时不要强行覆盖设备组件。

## 试读与自动收书

在应用导入文件，或登录自己的书源账号后搜索版本。点击「试读」打开该文件，打开成功后，同一版本的按钮变为「下载」。确认下载后，桌面将同一份原件上传并校验，再发布设备领取清单。

在增强模式下，Kindle 联网且 KOReader 运行时会后台检查专用网盘目录并接收缺少的书籍；打开或唤醒后约 8 秒检查，持续运行时约每 90 秒检查一次。它不远程唤醒设备或自动开启 Wi-Fi。暂停同步会暂停自动领取，恢复后继续。上传完成后电脑可以关闭，设备收到并校验后才显示「已在 Kindle」。

笔记、标注、真实阅读统计由 Kindle 上传到网盘，电脑再从网盘读取。头像和休眠封面设置优先通过同一局域网传输，直连不可用时回退到网盘。休眠封面使用设备本机最新阅读记录，离线仍可显示。

## 电脑试读需要什么

EPUB／PDF 可选择浏览器近似预览，不需要 WSL。要使用与设备同版 KOReader 的原生分页预览，需要电脑已经安装且能启动 **WSL Ubuntu**；应用不会自动安装系统虚拟化组件。其他 KOReader 支持格式通常需要原生预览，部分格式还可能需要单独安装 Calibre。

原生预览复用最近同步的设备字体及排版设置。设备改过字号、字体或页边距后，先保存退出书籍并同步，再在电脑 Aa 中重新加载设备排版。相同引擎与配置有助于保持分页一致，但不表示所有书籍都已逐页比对，电脑也不能复现电子墨水屏的物理效果。

## 当前边界与遇到问题时

手写笔记依赖设备上传原件及标题索引；索引缺失会显示「未识别标题」，部分特殊笔刷和模板还不能完整还原。平台 DRM 文档不支持试读或传送，书源可用性、下载额度和网页验证由服务提供方决定。

升级前建议备份应用个人资料与 Kindle 原件。卸载程序默认保留应用资料；源码目录、安装目录与个人资料目录是不同的位置。隐私处理见 [PRIVACY.md](../PRIVACY.md)，安全报告见 [SECURITY.md](../SECURITY.md)。报告问题时请勿附上个人书籍、笔记、配对包、授权文件或完整账号会话。
