# Kindle 原生体验与增强组件

Kindle 原生界面负责原生阅读、系统键盘和 Scribe 手写笔记。KOReader 是可选的另一个阅读器，其实验手写编辑器保存独立副本，不能代替原生 NBK 编辑与保存。原生 `.notebooks` 和实验 `.scribe` 副本继续保留。

## 本次组件更新

- 触屏 Kindle 首次运行更新组件时启用屏幕键盘，处理外接键盘误识别导致的搜索输入框无键盘。仍可使用真实外接键盘；菜单中的 Enable on-screen keyboard 可再次恢复屏幕键盘。
- KOReader 启动、唤醒或联网后先安排收书，笔记备份随后运行。轮询仅在 KOReader 运行、未休眠且已经联网时执行，不主动唤醒设备或连接 Wi-Fi。
- 收书遇到当前同步占用时保留待办，结束后补查。打包和每两包上传之间会检查是否该让出时间收书；当前单个传输仍需完成，不保证固定秒数内送达。
- 首本书校验落盘后发送回执，不等待后续笔记备份完成；收到新书时使用短暂提示。后续任务失败时会说明已收到的书仍可阅读。
- Kindle 设备上的 Notebook 标签默认保存并退出 KOReader，回到原生系统。随后在 Kindle 的 Notebooks 中打开原生笔记。插件菜单始终提供 Return to Kindle；Use experimental notebook editor 可主动启用实验入口。

## 原生增强模式还需要完成的工作

目前持续自动调度仍由 KOReader 插件运行。退出到原生系统后，已启动的独立同步进程可以继续完成，后续定时检查不会继续。这次组件更新尚未提供原生后台常驻服务、开机或原生唤醒触发。

完整原生增强应把“阅读界面”与“同步组件”分开配置：由独立组件在设备唤醒、已联网时同步；书籍进入原生系统能识别的目录和格式；电脑分别显示已上传、已落盘及原生书库可见。EPUB 直接拷贝到磁盘不等于能在原生 Kindle 阅读，现有 Send to Kindle 邮件流程可负责官方转换，也可另行验证本地 AZW3 转换及原生索引。原生手写文件优先做稳定快照和标题关联，不自动覆盖原生 NBK；原生阅读时长尚未接入，不能使用 KOReader 时长代替。

组件更新需先保存并退出 KOReader，通过 USB 安装并逐文件校验。更新包不含个人书籍、笔记、头像或授权；保留已有授权与暂停状态。真机键盘、休眠、网络、原生返回及耗电表现仍需用户设备验收。
